# 手感同步助手（FPS / 桌面）

在**不同设备 / 不同外设**之间获得一致的鼠标手感。包含两个场景：

## 场景一：FPS 游戏手感（主要）

需求场景：**同一款 FPS 游戏、同一个游戏内灵敏度**，在不同大小的屏幕（16.1 寸笔记本、24 寸显示器等）上获得相同的「画面物理位移」手感；鼠标 DPI 通过鼠标驱动软件在各设备上同步。

核心结论（来自《关于DPI的设置讨论》的延伸）：

- 以「鼠标移动 1cm，画面相对准星滑过的物理距离 cm」为手感基准：
  \[
  \text{画面位移} = \text{DPI} \times \text{灵敏度} \times \text{yaw} \times \frac{\text{屏幕水平宽}}{\text{FOV}}
  \]
- 同一款游戏、同一灵敏度、同一 FOV 时简化为 **DPI × 屏幕水平宽 = 常数**——所以换屏只需要按比例改 DPI：
  \[
  \text{DPI}_B = \text{DPI}_A \times \frac{\text{屏宽}_A}{\text{屏宽}_B}
  \]
- **分辨率、Windows 显示缩放、屏幕型号都不影响游戏内效果**（Raw Input 直读鼠标计数），缩放只影响桌面。

使用方式：录入每块屏幕的名称与水平宽（cm），指定基准屏幕与基准 DPI，程序给出各屏幕的「推荐 DPI」；在各设备上用鼠标驱动软件同步该值即可。

⚠️ 前提：游戏开启 Raw Input / 原始输入，并关闭鼠标加速度；更换游戏或改动游戏内 FOV 后需重新在基准屏幕校准一次基准 DPI。

## 场景二：桌面指针手感（备用）

需求场景：不同屏幕（分辨率、物理尺寸、系统缩放不同）之间，桌面光标保持相同的物理位移感。

核心公式：

- 有效水平像素 = 水平分辨率 ÷ 缩放系数；
- 有效 PPI = 有效水平像素 ÷ 屏幕水平物理宽度；
- 推荐 DPI = 手感倍率 × 有效 PPI（或按基准 DPI ∝ 有效 PPI 等比换算）。

⚠️ 注意：桌面光标受 Windows 缩放影响（逻辑分辨率变化），缩放比例务必按实际填写；且必须关闭「提高指针精确度」。

## 使用方法

### 单机使用（任意系统）

直接双击打开 `index.html`（Chrome / Edge / Firefox / Safari，Windows / macOS / Linux / 手机平板均可）。

### 局域网多端访问（手机 / 平板 / 另一台电脑）

```bash
node server.js
```

（Windows 也可双击 `start.bat`）启动后终端会打印本机地址（如 `http://192.168.x.x:8090`），同一局域网任何设备浏览器打开即可。Windows 首次监听可能弹防火墙授权，选择「允许」；端口默认 8090，可用 `PORT=9000 node server.js` 修改。

### 多端同步配置

1. 在设备 A 编辑好配置，点击「导出配置 JSON」（或「复制配置文本」）；
2. 在设备 B 打开本工具，点击「导入配置」选择该文件。
